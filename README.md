# Cinematic Presentations

A reusable skill for creating presentation websites with spatial storytelling and purposeful animations.

[View an example presentation](https://pii-guard-presentation.catinice.workers.dev/)

## Use

Place this repository in your agent’s skills directory as `cinematic-presentations`, then invoke `$cinematic-presentations` with your content.

The skill gathers the audience, goal, source material, speakers, visual preferences and delivery requirements. It asks you to design the story flow and agree on a concrete storyboard before substantial implementation.

It supports connected visual scenes, explanatory animation, restrained on-screen text, speaker notes, manual or automatic progression, reduced motion, responsive layouts and offline delivery.

## Files

- `SKILL.md`: discovery, user-authored flow, design, implementation and delivery workflow.
- `references/visual-storytelling.md`: content-specific structures, scene design and visual continuity.
- `references/playback-and-verification.md`: playback behaviour, camera motion, accessibility and browser checks.
- `agents/openai.yaml`: skill interface metadata.

The skill contains general instructions, with no example-site source code, private source documents, personal records or credentials. The linked presentation is a separate hosted example.
